# 微信模式版本

打开 `index.html`，进入「设置」，点击顶部的「微信模式」开关即可启用或关闭。选择会保存在浏览器本地，下次打开会沿用。

本次改动只重排和美化原网站已有功能，没有新增 p2 中原网站不存在的业务功能。p2 引用的 11 个图床素材已下载并封装为 `assets/` 下的本地 SVG，微信模式本身不再请求这些图床地址。

微信模式下，左侧语音外观按钮仍执行原来的「+」展开功能，独立笑脸按钮打开原表情包，右侧「+」按钮代理原来的「继续说」功能；旧继续说按钮与发送键均不显示，输入内容可继续使用回车发送。对方输入时，聊天区提示隐藏，顶栏固定显示「对方正在输入···」；消息下方的发送时间与已读状态也会隐藏。设置等非主界面保持原网站主题。

微信模式开启期间会强制为双方每条消息显示头像，并把引用卡片放在消息气泡下方；关闭模式后，头像显示、单侧隐藏和引用位置会恢复为开启前的设置。

微信模式继续使用原有的「设置 → 外观设置 → 背景 & 字体」来选择图片、GIF 或预设背景，不增加独立窗口。微信聊天层会直接读取当前背景变量，因此切换背景、重新载入页面或恢复会话后都能保持显示；顶栏使用约 95% 不透明度的浅灰叠层，不添加模糊滤镜。

文件说明：

- `index.html`：原网站功能主体，已接入微信模式。
- `wechat-mode.css`：微信日间布局与视觉样式。
- `wechat-mode.js`：模式开关、持久化与运行时兼容处理。
- `assets/`：本地 SVG 素材。
