# 微信模式版本

打开 `index.html`，进入「设置」，在顶部「微信模式」中选择「关闭 / 日间 / 夜间」。选择会保存在浏览器本地，下次打开会沿用。

本次改动只重排和美化原网站已有功能，没有新增 p2 中原网站不存在的业务功能。日间与夜间参考中的图床素材均已下载并封装为 `assets/` 下的本地 SVG；夜间的返回、更多、加号、表情、发送、语音、翻译、转账和左右气泡尾巴都有独立文件，不再复用或反色日间图标，也不会在微信模式中请求图床地址。

微信模式下，左侧语音外观按钮仍执行原来的「+」展开功能，独立笑脸按钮打开原表情包，右侧「+」按钮代理原来的「继续说」功能；旧继续说按钮与发送键均不显示，输入内容可继续使用回车发送。对方输入时，聊天区提示隐藏，顶栏固定显示「对方正在输入···」；消息下方的发送时间与已读状态也会隐藏。设置等非主界面保持原网站主题。

微信模式开启期间会强制为双方每条消息显示头像，并把引用卡片放在消息气泡下方；关闭模式后，头像显示、单侧隐藏和引用位置会恢复为开启前的设置。

微信模式继续使用原有的「设置 → 外观设置 → 背景 & 字体」来选择图片、GIF 或预设背景，不增加独立窗口。微信聊天层会直接读取当前背景变量，因此切换背景、日夜模式、重新载入页面或恢复会话后都能保持显示；日间与夜间顶栏都使用约 95% 不透明度的叠层，不添加模糊滤镜。

气泡几何按 440px CSS 视口的参考截图校准：文字、语音、引用及扩展内容共同受 `294px` 最大宽度约束，窄于该尺寸的屏幕会根据头像和页面留白自动收缩；尾巴保持 `17 × 17px`、左右 `-17px`，垂直位置统一为 `12px`。

文件说明：

- `index.html`：原网站功能主体，已接入微信模式。
- `wechat-mode.css`：微信日间/夜间布局、引用卡片与视觉样式。
- `wechat-mode.js`：关闭/日间/夜间切换、持久化与运行时兼容处理。
- `assets/`：本地 SVG 素材。
